# Мини-блог (Social Post API)

Тестовое задание: реализация бэкенда и фронтенда для создания и просмотра постов.

## 🛠 Стек технологий
- **Бэкенд:** Python 3.11, FastAPI, SQLAlchemy, SQLite.
- **Фронтенд:** HTML, CSS, JavaScript (Fetch API).
- **Документация:** Автоматическая OpenAPI-схема (Swagger UI).
